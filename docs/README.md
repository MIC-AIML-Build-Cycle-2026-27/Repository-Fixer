# Documentation

Project documentation lives here. Keep it short, current and useful to someone joining the team.

| File / folder | Contents |
|---|---|
| [`architecture.md`](architecture.md) | System design: components, data flow, key decisions |
| [`updates/`](updates/) | Weekly updates and review preparation notes |

Add files as the project needs them, for example `setup.md`, `evaluation.md`, `datasets.md` (where data comes from and how to obtain it), or `decisions/` for recording important technical choices.

Department-wide guidance: [Build Cycle Handbook](https://github.com/MIC-AIML-Build-Cycle-2026-27/build-cycle-handbook/blob/main/docs/documentation-guide.md)
