# Weekly Updates

One file per week, named `YYYY-MM-DD.md` (the Monday of that week).

Copy the template from the handbook: [`templates/weekly-update.md`](https://github.com/MIC-AIML-Build-Cycle-2026-27/build-cycle-handbook/blob/main/templates/weekly-update.md)

Review preparation notes can go here as `review-1.md`, `review-2.md` and `final-review.md`, using [`templates/review-update.md`](https://github.com/MIC-AIML-Build-Cycle-2026-27/build-cycle-handbook/blob/main/templates/review-update.md).
